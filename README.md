# quiling.net
Makes quiling framework usable in C#
Idea: i will make a C# wrapper, that uses python-embeddable packages to run quiling framework with a local python. I will do the running with Cli Wrap so it is invicisible. Releasing of the project willl be done completely in github actions, first the download of the python, then the installment of qiling, then the building of the C# wrapper that uses those executables.
